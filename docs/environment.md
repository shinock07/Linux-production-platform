#Development Environment

## Operating System

- OS: Ubuntu 26.04.1 LTS
- Environment: WSL2
- Init system: systemd

## Hardward Resources

- CPU cores: 16
- RAM: approximately 11 GiB
- Root filesystem: approximately 1007 GiB

## Networking

- Interface: eth0
- SSH: Port 22
- Network is provided by the WSL2 virtual network

## Development Tools

- Git
- OpenSSH client
- systemd

## Purpose

This WSL2 environment is used as the development and testing
environment for the Linux Production Server & Deployment Platform.

A separate Linux server will later be used as the production
deployment target.
